# APSthai CRM v2

## Run locally
```
npm install
npm run dev
```
Open http://localhost:3000 and sign in with your username.

## Deploy
Import this repo in Vercel (framework: Next.js). No environment variables are needed.

## Database
Supabase project `apsthai-crm-sg`. Migrations named `crm_v2_*` build the schema; see CLAUDE.md.
